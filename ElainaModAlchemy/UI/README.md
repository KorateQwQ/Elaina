# 炼金手记

伊蕾娜右键交互距离内的大锅后入位、翻书并打开手记，不再注册打开手记的快捷键。Esc 或右上角关闭按钮合上手记，右键同一口锅可重开并保留选中条目与滚动位置。普通烹饪锅不触发。

炼制由 `Gameplay/AlchemyBrewingPlayer` 与 `AlchemyBrewSession` 独立管理：点击炼制只登记配方和批数，按实际炼金制作等级决定本轮时长，1级240帧（4秒），8级60帧（1秒），中间线性缩短并取整到游戏帧；1～99批共用一次等待。完成时才通过原版合成接口重新收集材料、检查、扣料、发放成品并结算经验。结束时批数不足则只完成当前材料支持的批数；任何未完成批次都不扣料。关书不会打断搅拌，重开不会重置进度；手记未关时结束后恢复翻书，已关时结束后解除入位。受伤、死亡、大锅失效、角色切换或离开大锅会取消尚未结算的任务，不保留到下次进世界。

`Gameplay/AlchemyEfficiency` 集中管理效率：实际炼金1～8级额外产出概率依次为0/5/10/15/20/25/30/35%。每个成功批次独立判定，触发时额外给予该配方一份基础产量，不额外消耗材料、不增加制作经验；仅大锅配方参与。一次批量操作使用结算前的等级判定概率，不因同一轮获得经验而提高后续批次概率。技能属性显示当前实际等级的炼制速度加成百分比和产出率；升级预览显示达到当前/下一技能上限后的数值，研习点升级仍只提高制作等级上限。速度加成以1级为基准，使用实际游戏帧耗时换算，8级显示+300%，不在玩家描述和预览中显示秒数。显迹尘配方为闪耀根1＋晶状体1→3份。

翻书与搅拌沿用原角色帧图，新绘制层替换完整角色姿势，帽子和项链读取同一动画帧。 人物、帽子、项链与凳子统一使用 `AlchemyBrewAnimation` 的地面基准：翻书脚底在地面，搅拌脚底垫高 7 像素，凳子按纵向 0.25 倍压缩并与脚底接合，棍尖与锅口齐平，凳脚固定在地面；不再依赖旧版 `portableStoolInfo` 状态、全局凳子绘制钩子、腿帧或原版头部姿态补偿。旧版开锅、物品槽、克隆、炸锅与镜头流程已删除；`炼金modplayer` 仅保留旧存档字段，供两处旧法术熟练度读取。联机包只同步姿势、大锅位置和动画时钟，物品与材料仍通过原版客户端合成和同步路径处理。

手记正文和随笔采用伊蕾娜本人的口吻：涉及自己的手艺、喜好与旅途经历时用第一人称，避免以旁观者视角介绍“伊蕾娜”或“她”。客观配方与效果记录保持简明；角色适用范围仍用明确的角色名称区分。中英文文案同步遵循这一视角。

## 真实制作与材料

已移除生产代码中的演示库存。`AlchemyNotebookState` 只管理导航，数量与资格由 `AlchemyNotebookSource` 读取角色和原版合成材料统计。

`Gameplay/AlchemyVanillaRecipes.cs` 在正常配方加载阶段注册 17 条实际 `Recipe`，配方带“仅在炼金手记中制作”条件，不会绕过研究出现在普通合成栏。材料收集直接调用安装版本的 `Recipe.CollectItemsToCraftWithFrom`；是否足够调用 `Recipe.CollectedEnoughItemsToCraftRecipeNew`；点击制作调用原版 `Main.CraftItem`，包含 `Recipe.Create`、材料消耗钩子、物品创建/制作回调、前缀与箱子同步。

因此材料来源、消耗顺序及替代材料组遵循原版：背包、打开的箱子/个人容器、启用的虚空袋，以及 `AddMaterialsForCrafting` 提供的材料。铁/铅、椎骨/腐肉以正式 RecipeGroup 注册。批量制作逐批重新检查，材料被其他逻辑改变时只报告实际完成的批数。

成品通过原版 `Player.GetItem` 放入背包，放不下的部分在玩家位置掉落；手上已有的鼠标物品会保留。姿势同步由炼金状态包处理，材料变化沿用游戏已有同步。

灰赝尘默认不参与炼金。以后将 `AlchemyVanillaRecipes.AllowFacsimileDust` 设为 true，即可同时启用现有灰赝尘系统的材料判定、最大批数和实际补料消耗；无需重写扣料逻辑，已有正常合成功能不变。

## 研究与成长

`Gameplay/AlchemyProgressPlayer.cs` 用角色存档保存已研究条目、等级与经验，不与旧 `炼金/` 系统混用。新角色等级为 1、经验为 0，所有素材（`Category == "material"`）统一初始解锁，无需等级或配方研究，直接显示真实图标、名称与获取方式；其他标记为初始解锁的条目同样直接可用。读取旧角色存档和重置手记时都会自动补全素材解锁，不发放物品、不改变制作或购买条件；其余未研究条目隐藏图标、名称、效果和制作材料，只显示问号与研究条件。

炼金术为被动技能，`ElainaModSkills/Data/SkillBalance.json` 中的 `AlchemySkill` 决定解锁与成长节点。角色等级达到 6、进度等级上限达到 10 后可学习；成长节点为 6、10、15、20、25、30、35、40……，肉山后的角色等级上限为 40，对应技能可升至 8 级。配方手记的当前等级上限读取实际已学的炼金术等级（未学习时为 1，保留系统最高 20 级限制），不会因角色推进 Boss 进度自动发放技能等级或炼金经验。

经验规则集中在 `Gameplay/AlchemyProgressionRules.cs`：1→2 级需要 **100 XP**，之后每级增加 **50 XP**；每批制作获得 **10 + 5 × 稀有度**经验，按批数而非产物件数计算。只有成功制作才给经验，到达技能决定的上限后停止累积，升级技能后可继续成长。旧存档和技能重置时保留已获得的等级、经验及研究记录，展示和研究判定使用受当前技能上限限制的等级，重新提升技能后恢复既有进度；读取存档不依赖技能的加载顺序。`RequiredLevel(id)` 集中配置各条目门槛。

2026-10-26 确认为首版方案，目标是各阶段常规备药、料理和探索制作能够逐步支撑升级，不要求开放上限后立即练满。保留阶段封顶，不预存经验；本次确认与原有公式相同，不转换旧经验或追补历史制作。参数集中为 `InitialLevelExperience`、`ExperienceIncreasePerLevel`、`BaseBatchExperience`、`BatchExperiencePerRarity`。

`Gameplay/AlchemyRecipeSources.cs` 集中配置获取方式：星力由巫师出售，集中由军火商夜晚出售，共鸣由巫医夜晚出售，基础买价均为 5 金（随原版商店价格调整）；嗜血由肉后血月的战斗敌人按基础 1% 概率掉落。友好 NPC、城镇 NPC、无战斗能力/无价值敌人、雕像生成物及共享生命的从属节段不掉落。商店与掉落不因个人已研究而隐藏，多余配方可以留给其他角色。

`Gameplay/AlchemyRecipeChestLoot.cs` 在新世界的 `PostWorldGen` 中只登记天然宝箱，伊蕾娜本人或她的人偶成功开箱时才判定配方。轻羽候选仍为地下至地狱上方的普通金箱（`Containers` 样式 1）。尚未获得时概率从 20% 起，每次未出增加 10 个百分点，第 9 个有效箱必出；曾获得后固定 5%。每次成功追加配方 ×1，只使用空槽，保留原奖励。

止痛药仅登记天然常春藤宝箱（`Containers` 样式 10，含丛林神龛与生命红木树中的箱子）；红木箱、神庙箱、地牢丛林箱以及丛林环境中的其他箱型均不参与。首次获取依次为 **30% / 60% / 100%**，最多 3 个有效箱必出；曾获得后固定 **5%**。止痛药与轻羽分别累计。玩家可见获取描述保持原有文字，不展示概率与保底数值。

每张配方单独累计连续未出次数；成功放入箱子清零，实际拿到背包、鼠标、个人仓库或人偶携带物时才永久记为曾获得，已研究也会补认。记录随角色存档，消耗、丢弃、技能重置不清除。箱子的判定机会按世界共享，其他角色先开不消耗，已判定的箱子不会因重新开关或读档重抽。满箱暂不结算，腾出空位后重新打开再判定；箱内已有对应配方时不重复添加。玩家新放置、拆除后重放、复用槽位的箱子都不会继承资格。旧世界不扫描或回填。

联机在 `AlchemyRecipeChestHooks` 中观察原版有效开箱请求，并在服务器发送第一个 `SyncChestItem` 前完成投放；40 个槽位之后才发送打开消息，不以客户端打开后的补发方式插入配方。角色历史在开箱请求之前按同一连接同步，服务器统一抽取；普通物品槽同步不会触发抽取。验证入口：`pwsh -File Tools/AlchemyChestChecks/run.ps1`，使用编译后的正式代码与真实 tML 开箱消息处理；完整双客户端延迟体验仍需游戏内验证。

未研究详情显示配方图标、名称、背包数量、等级条件、消耗说明和获取来源。每个 `AlchemyItem` 仍可以覆盖 `ResearchRequirement`：

```csharp
// 仅等级：达到 5 级后，点击研究。
public override AlchemyResearchRequirement ResearchRequirement => new(RequiredLevel: 5);

// 配方物品：填入对应配方类的 ModContent.ItemType。
public override AlchemyResearchRequirement ResearchRequirement => new(
    RequiredLevel: 1,
    RequiresRecipe: true,
    RecipeItemType: ModContent.ItemType<YourRecipeScroll>(),
    RecipeStack: 1,
    ConsumeRecipe: true);

// 每批经验也可以逐物品覆盖。
public override int CraftExperience => 20;
```

配方物品按背包检查；`ConsumeRecipe` 控制研究后是否消耗。设置 `RequiresRecipe=true` 而配方类型仍为 0 时，研究保持禁用，不会误解锁。已研究条目不能重复消耗配方。

## Debug

与技能表一致，等级 +1、升满级、解锁所有配方、补充素材、重置手记按钮及相应操作使用 `#if DEBUG`。

- 补充素材：给予当前配方单批需求的 **10 倍**，与数量选择器无关；替代材料组给予其中一种，优先放背包，满包落地。
- 重置手记：清空非初始条目的研究记录，恢复等级 1、经验 0，保留全部素材及其他初始条目的解锁和真实物品。
- 等级 +1：每次提升一个炼金等级，保留当前经验和研究记录；达到炼金术技能决定的当前上限时经验归零，按钮显示「已满级」并禁用。制作中不能升级。
- 升满级：直接达到炼金术技能决定的当前等级上限，经验归零，保留研究记录和物品；已达上限时禁用，不修改技能等级。
- 解锁所有配方：跳过等级和配方卷轴条件，解锁手记目录全部条目，不消耗卷轴、不发放物品、不改变等级经验；全部解锁后显示「已全部解锁」并禁用。解锁和满级均随角色存档保存，可用「重置手记」还原。
- 制作中或状态忙碌时所有调试按钮禁用。Release 构建不创建这五个按钮，也拒绝相应操作。

## 绘制与资产

魔力名称沿用物品说明中的 `klicon` 图标与颜色标签。`AlchemyDrawing` 将魔力图标和名称作为一个行内单元测量、缩放和换行，绘制实际 `Snippets/MagicStarIcon.png` 及蓝色文字，不使用星号字符替代。普通文本保持原绘制路径。

`Tools/AlchemyPreview/run.ps1 -StarPowerOnly -Culture zh-Hans`（英文为 `en-US`）只预览星力条目，在 720p、常规尺寸及 125% UI 缩放下检查这一行内单元。全量预览现在检查实际使用的新纸卡、星形和描边资产，不再要求已停用的彩铅素材。

外框沿用技能表的紫色书页主题，纸页使用炼金专属 `Assets/NotebookSurface.png` 连续渐变底图，避免技能星图裁剪区域带来的横向底色断层。底图直接取技能页底图，按 10px 网格求平均、高斯模糊（约 30px）后再用 B 样条放大，两本手记的光斑（目录区一团、详情栏上方一团）位置与亮度一致，但去掉了技能底图的矩形拼接边；加了确定性抖动，避免 8 位色阶环。改底图后须重跑 `bake_redesign.py`，淡出条是从底图裁出来的。用 `python Tools/AlchemyPreview/bake_surface.py` 重建，图片为 1100×800 不透明 RGB，按 RGBA8 加载约占 3.36 MiB，运行时缓存并单次绘制。技能表底图不受影响。局部辉光仍使用同一张 Glow.png。23 个炼金物品使用 `item/ExampleAssets/*_Pixel`，目录与详情按原图 1 倍居中绘制，随整体 UI 缩放。配方与底部素材栏中的 29 种原版材料，通过现有物品 ID 和 `Main.GetItemDrawFrame` 读取游戏贴图及当前动画帧，在槽位中居中绘制，保留原尺寸，只在超出槽位时缩小。右侧详情内容宽度比滚动区域窄 10 设计像素，为滚动条留出间隔。所有像素图标使用 `PointClamp`，绘制后恢复原批次状态；未研究剪影、字体和装饰保持现有绘制。

**物品像素图的外轮廓必须是纯黑 `#000000`。** 纸卡上不画描边光环，深紫灰（如 `#51415f`、`#332f43`）的外轮廓在浅紫纸面上会糊成一片，物品形状不清楚。规则只管外轮廓，也就是与透明像素或画布边缘四邻接的不透明像素；瓶塞分隔线、蝴蝶结内线等内部线条可以继续用深紫灰。新画或重画的贴图按此执行，绘制约定见 `Tools/PotionPixel/README.md`。

未研究物品使用 `Assets/MysteryPixel/*_Mystery_Pixel.png`：沿用对应物品像素图的画布和轮廓，问号直接绘进透明贴图，在手记中与已研究图标同样按原图 1 倍、Point 采样显示。修改物品像素图或新增目录条目后，运行 `python Tools/AlchemyPreview/prepare_mystery_pixels.py` 更新对应问号图。

选中羽毛取自 HTML 注脚的 `notebook-quill`，注脚自身不再绘制羽毛。封面、选中标记、字体、滚动裁剪与开合动画继续沿用已实现版本。

`AlchemySelectionQuillMotion` 只对更换选中条目进行路径缓动。目录滚动与面板移动通过当前绘制帧的卡片坐标同步应用；落定后相对卡片的偏移归零。羽毛笔锚点跟随选中卡的位置偏移、抬起和缩放，但不随倾斜旋转。羽毛笔与选中卡一起放在目录原生遮罩内的独立叠加层，不参与卡片排版、不拦截输入；快速重新选择从当前动画位置继续。

### 页面滚动

主目录与详情页隐藏竖向滚动条，支持滚轮和鼠标左键拖动非交互区域。按住物品卡、材料行或用途链接不会启动拖动；拖动过的详情行不会在松手时误触链接。共用的 `System/UI/ElasticPageScrollView` 将 SUI 坐标转换为页面设计坐标，`ElasticScrollMotion` 统一处理拖动阻力与滚轮越界回弹（最多 32 设计像素），不改变原有视口裁剪。选中条目仍可自动滚动到可见位置。离线检查见 `Tools/AlchemyPreview/run.ps1 -ScrollOnly`。
