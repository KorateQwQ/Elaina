# 魔女手札独立预览

参考 `../NewUIExample/elaina-battle-eight-skills.html` 的最终 CSS 与 JavaScript。进入世界后按技能面板快捷键（默认 **V**），或输入 **`/elainapreview`**。再次按快捷键、Esc 或右上角关闭；帮助开启时 Esc 先关闭帮助。入口仍为 `ElainaSkillModPlayer.HandleOpenCloseSkillPanel()`，一次按键只切换本预览，默认关闭。

## 接入范围

这是独立的 SUI `BaseBody` 演示：研习、进修、心得开关和八槽装配不读写真实角色成长、技能、背包、存档或网络，也没有接入实际施法。关闭重开保留演示状态；退出 UI 树／重新进入世界时恢复初始状态。HTML 外围战斗栏、生命魔力 HUD、药水和物品切换不属于此预览。

## 样式与交互

顶部细化：书页最上方 146 像素使用按 HTML 渐变与内阴影生成的 `HeaderSurface.png`，减小原底图偏灰的色差。顶部数字和 ESC 使用项目已有 Gelasio，标题保留 NotoSerifSC，并在同一采样位置补充笔画覆盖；修正标题基线、分类数量间距、星尘右对齐和 ESC 位置，补充进度星点的柔光。图标资产、星空和详情绘制不受此细化影响。复现和倍率对比见 `Tools/NotebookPreview/README.md`。

- 1100×800 逻辑尺寸，83 高页眉、62 高导航、580 高内容区和底部八槽装配。较小屏幕或较高 UI 缩放下等比适配，四周预留 16 逻辑像素。
- 顶部为“魔女手札”和星尘。四种状态导航为“已习得／待研习／待启封／未显现”，显示实时数量。初始选中旅途的起点，分类数量 3／3／4／2。
- 术式采用开放菱形端角与贴图角标，心得采用双层矩形端角，隐星采用虚线方框和月牙星形。已习得节点显示固定宽度等级标签；满级使用金色，失效图标变灰，未匹配分类淡化。隐藏状态不泄露名称和真实条件。
- 星图视口 727×473，坐标空间 727×550，默认缩放 84%，范围 50%～150%。支持拖动、鼠标锚点滚轮缩放、缩放按钮、归位、双击空白归位及关系跳转。
- 详情标题和底部操作固定，中间使用 `SUIScrollView`。正文、属性、心得开关与关联、失效原因、等级／下级对比／进修、依赖和前置按实测高度纵向布局。月华飞弹包含飞弹伤害、引爆伤害、魔力回复的动态说明及对比。切换条目回到顶部，内容收缩时夹紧滚动位置。
- 点击节点同步其分类；切换分类保留匹配选项，否则选中首项；空分类显示“暂无”并禁止旧条目的操作。关联、依赖和前置采用可点击图标，跳转后居中显示节点。
- 装配槽为 01～08，支持替换、跨槽移动、清空、节点槽位标记和失效暗化。已习得但暂停生效的术式仍可装配；心得无需装配。
- “重置手札”直接执行：恢复初始技能、等级、心得与 18 星尘，清除失去所有权的装配，保留初始之焰的已有槽位；全部为空时补到 01 槽。目标槽保留。关闭预览不重置。
- 帮助阻挡底层输入；关闭、失焦或弹出帮助结束拖动。详情滚轮与星图缩放分别处理。

## 演示规则

初始技能为旅途的起点、魔力感知、初始之焰，各一级。研习和进修共用 18 星尘预算，费用与成长参数来自 HTML。研习前置、隐星揭示、生效依赖分别计算；“待研习”分类只表示前置满足，按钮另检查余额。

魔力感知可开关，关闭后递归暂停月华飞弹、月影回响、魔女的结界和月下的奇迹，但保留习得、等级和装配；不暂停非依赖分支。它的魔力折扣作用于全部术式。旅途的起点只提供魔力上限成长。模型提供循环依赖保护。所有效果数值仅用于预览展示。

## 实现与资源

- `ConstellationPreviewUI.cs`：窗口、星图、状态导航、节点、固定详情、八槽和入口生命周期。
- `PreviewDetailUI.cs`：原生 SUI 滚动容器、可复用行控件、命中和动作处理；不在每帧重建控件。
- `PreviewDetail.cs`：按实际字体度量生成的详情内容行、绘制及局部操作区域。生产 UI 和离线预览共享此内容。
- `PreviewData.cs`：独立演示状态、预算、成长、有效性、关系、装配与重置。
- `PreviewDrawing.cs`：标题使用 KL `FontManager.NotoSerifSC`，正文使用 `HarmonyOS_Sans_SC`，槽号使用 `Gelasio`。测量、换行和最终绘制使用相同字体；文字不烘焙成图片。技能图复用 `ElainaModSkills/Icon/` 的原图与原有零 Alpha tint，支持真实透明度和缓存的灰度变体；变体在退出 UI 树时释放，原始 ModContent 资源不手动释放。
- `ImportReference.cjs`：执行 `node ElainaModSkills/ElainaSkillUI/ConstellationPreview/ImportReference.cjs` 同步 `Assets/Skills.json`。只解析指定数据声明中的字面量，不执行 HTML 脚本；导入技能、成长费用、月华飞弹效果、生效依赖，并验证关系与贴图路径。原始项目技能贴图映射保留，不导出 HTML 的 Base64 技能图。

**保留的绘制：**星空的固定柔光星点、同心轨道、倾斜椭圆、72 个刻度，以及现有金色前置连线、已习得紫光、待研习／隐藏虚线，均继续使用现有绘制和资产。新版 ready 状态映射到原连线 available 状态；不引入新版 suspended 连线样式。只调整新布局位置、视口和筛选状态。

左上角继续使用现有 `Assets/HeaderHat.svg` / `HeaderHat.png` 和配套圆环菱形，仅随页眉平移；没有重新生成或替换帽子。既有绘制参考伊蕾娜动画官网 https://majotabi.jp/#Character 的人物设定，保留弯帽尖、宽帽檐、菱纹缎带及珠链挂饰。

现有 `Page.png`、`StarfieldBase.png`、`Glow.png`、连线纹理、`Stars.png` / `Stars.json` 不重新生成。星形仍复用 KL 实际绘制离线生成的多尺寸图集。旧资源生成工具继续保留；本次数据同步仅运行导入器。
