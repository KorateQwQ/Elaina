# 经验光球

敌对 NPC 死亡时，单机/服务器向 1200 像素（75 格）内每名存活伊蕾娜各生成一颗独立光球，无需击杀归属、不平分奖励。2026-10-26 起普通怪按 `max(1, floor(基础最大生命 / 10))` 计经验；同日按用户要求降低升级需求，现为 `100 + 10 × (L−1)`（每级增加 10），集中在 `System/Experience/ExperienceRules.cs`。肉后暂沿用曲线，尚未完成平衡。

`ExperienceNpcRules` 用 NPC 的 netID 创建普通难度、单人、单位强度的独立默认实例，支持模组 NPC 和负 netID 变体；每世界按 netID 缓存，不改变全局难度或共享 ContentSamples。第三方模组若绕过标准 spawnparams、直接读取全局难度或自己缩放基础值，仍需适配。Boss 标记与现有 KL 击杀回调一致；未标记为 boss 的小 Boss 按血量奖励。

Boss 复用 KL 的 `OnBossLoot / OnKillBoss` 参与击杀事件：角色拥有端首杀按击杀前等级上限计算一条经验的 25%（向下取整）并预留，再立即开上限。已首杀的角色改得补偿：`min(max(1, floor(realMaxHp / 200)), max(1, floor(当前等级升级经验 / 20)))`，无有效血量时为 0。`realMaxHp` 直接使用 KL 回调的第三个参数，来自服务器 `self.GetRealMaxHP()`，不另写 Boss 血量合计算法。0.5% 系数为小怪 10% 的 1/20，至多本级一条经验的 5%，首杀与补偿二选一。

`ElainaGameStateSystem` 同一回调在单机／服务器为参与名单中的存活伊蕾娜生成独立光球，不受普通怪的 1200 像素距离限制。服务器确认抵达后只发送该次击杀凭据，由拥有端消费预留金额一次并入账。每次击杀使用“稳定 Boss 身份＋本世界该角色参与击杀序号”，同种 Boss 多颗在途光球互不覆盖；每次 KL 回调视为一次有效击杀，同一名单内重复玩家只生成一次。客户端不请求生成、不向服务器提交奖励金额，Boss 本体不再同时按小怪血量规则多领一份。

首杀字符串身份随角色保存，原版世吞／双子／肉山／月总多体节合并。战斗结束与参与资格直接沿用 KL 的 `OnBossLoot / OnKillBoss`，不再扫描存活 NPC 或重复判断世吞／双子是否打完；共享身份仅用于持久化首杀防重。模组默认使用 ModName/NPCName，多种 NPC 类型组成的一场战斗尚需定义共享身份。旧存档保留历史浮点进度作为迁移豁免，不追补这些阶段首杀，但重新击杀可以领补偿；新首杀不再以浮点进度作为唯一身份。首杀资格归拥有端决定，每次击杀独立预留奖励，只显示本角色待领取的 Boss 球。击杀序号不随存档保存，进入世界／载入时重置，服务器按槽位与 Player 实例隔离；死亡仍观察事件并递增序号，只跳过光球生成。未吸收的金额不另行保存，死亡、离线、过期或离开世界与普通光球一样不发奖励。

排除城镇/友好 NPC、小动物、雕像怪、练习假人、弹幕型 NPC 和共享生命的从属节段；额外排除已知 Boss 部件，以及生成来源能追溯到 Boss 的召唤物及其后代。未提供可追溯来源的模组召唤物仍需适配。光球上浮 30 tick 后穿墙追踪固定接收者，超过最初分配范围仍继续追踪；死亡、离线、切换角色、过期只清理，不奖励、不转移。服务器 owner 为 255，ai[0] 为接收者、ai[1] 为普通怪经验（Boss 为 0）、ai[2] 为年龄；Boss 身份通过 ExtraAI 同步，netUpdate 确保首次自动生成包之后补齐身份。

服务器确认抵达且只结算一次，定向通知拥有者；拥有者通过现有 `ElainaStatePlayer` 存档保存经验与等级。该流程沿用角色本地存档模型，不是服务器托管角色系统。Boss 进度控制等级上限；到上限最多暂存一条经验，解锁上限后消耗。等级计算支持一次跨多级并保留余数。
