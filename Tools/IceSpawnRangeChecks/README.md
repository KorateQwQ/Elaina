# 冰锥出生范围

参数统一位于 `ElainaActions/Action_IceCone.cs` 顶部的计算属性，生成与游戏内范围框共用 `GetSpawnOffset`。

- `SpawnBackMin` / `SpawnBackMax`：瞄准轴线上的后方近端和远端，差值是弧形带的厚度。
- `SpawnSideRange`：中心弧弦长的一半，不含内外缘厚度。弧度变化时保持中心弧左右展开宽度。
- `SpawnArcDegrees`：完整圆心角（度），0 为原矩形，45 较平，90 较弯，180 为半圆。输入限制在 0～180。圆心会随弧度平移，轴线上的位置保持不变；两端向玩家方向弯曲。它不是以角色为固定圆心的攻击扇形，也不是鼠标瞄准角度。
- `PreviewSpawnRange`：是否在手持魔杖、选中冰锥术时显示范围边界。

极窄但很厚的形状会把内缘截在圆心，避免翻折；此时近端可能达不到指定值。左右宽度为零时退化为轴线。新出生点使用新的参数；已经生成的冰锥不重新定位。随机点按弧形带面积均匀分布。

本次按用户指定方式把字段调整为计算属性并增加共享几何/绘制方法，因此初次结构变更不是纯方法体 Hot Reload。建立可运行基线之后，调整已有 getter 的返回表达式是方法体编辑；具体是否接受由调试运行时决定。不要自动重启用户游戏。

运行 `python Tools/IceSpawnRangeChecks/run.py`。每次从当前动作源码提取两段实际方法；仅把属性返回值适配为测试输入，FNA 相机、玩家参考矩形和原版白像素使用最小桩。10 万点检查圆弧边界、左右对称、面积分布、接近零弧度的连续性及退化范围。

隐藏的独立 FNA 进程生成 `.vissandbox/ice-spawn-aim-preview/out/` 下的当前参数、0/45/90/180 度截图，以及 1366×768、1864×977（112.5%）和 2560×1440（150%）覆盖。只检查出生几何及实际范围线绘制，不模拟冰锥模型、碰撞、联机，也不证明游戏里的 Hot Reload 已应用。测试像素只在隔离工具中生成，正式代码复用原版资源。

工具模板为 `.cs.txt`；实际编译源码、DLL、截图放在 `.vissandbox`，由现有项目约定排除。生成器和模板保留在 `Tools`，不进入模组包。

## 实时调参窗口

运行 `python Tools/IceSpawnRangeChecks/run.py --live`，打开原生 Windows 调参窗口。右侧滑块和数值框控制弧度、近端、远端、左右展开宽度、固定瞄准距离及瞄准方向；左侧通过当前源码提取的 FNA 绘制方法实时重绘，自动缩放以显示整个范围。它是静态出生范围编辑器，没有飞行动画或模拟游戏时间。

- **保存参数 / 载入参数**：读写本工具目录的 `selected-aim-range.json`；没有新文件时可载入旧 `selected-range.json`，缺少的瞄准距离默认使用 600。启动默认读取当前 C# 属性值，保存文件可通过按钮载入。
- **读取代码**：重新读取五个属性当前返回的数值。
- **写入属性值**：只替换 `Action_IceCone.cs` 的四个范围属性和固定瞄准距离的返回值，保留其他代码；瞄准角度只是预览状态，不写入游戏。若这些属性自上次读取后被其他编辑器改动，会提示先读取代码，避免覆盖。写入之后由用户在 IDE 应用 Hot Reload，本工具不控制或重启游戏。
- **截图**：保存完整窗口到 `.vissandbox/ice-spawn-aim-preview/out/editor-时间.png`。`Ctrl+S` 保存参数，`Esc` 或关闭按钮退出窗口。

左侧使用真实出生映射和边界绘制，角色只用参考矩形表示；右侧是 Windows 原生调参控件，不是正式游戏 UI。预览只在参数或窗口大小改变时重绘，不持续分配 GPU 截图。生成器会构建独立的 Windows Forms/FNA 工程，正式模组工程和依赖不变。

`python Tools/IceSpawnRangeChecks/run.py --live-check` 以隐藏窗口检查滑块联动、FNA 重绘、近远距离约束、JSON 往返、临时副本的属性写入和冲突检测，并导出 `editor-current.png`、`editor-flat.png`、`editor-curved.png`。检查不会写入正式动作源码。实时进程编号保存在 `.vissandbox/ice-spawn-aim-preview/live.pid`，日志为同目录 `live.log`。

## 固定瞄准距离

`Action_IceCone.AimDistance` 是可调整的计算属性，默认 600 世界像素，按至少 1 像素处理。发射节点把 `玩家 MountedCenter + 瞄准方向 × AimDistance` 传给原有 `GetShotDirection`；真实鼠标只决定玩家的瞄准方向，不再决定每枚冰锥的偏转程度。虚拟点随玩家当前位置平移，每一枚新冰锥生成时采样；已经出生的弹幕不重新计算初始方向。

保留原来的 0.2 倍修正强度及 0.12 弧度上限。金色十字是计算角度的参考点，淡金线是按实际修正公式算出的初始直线方向，不代表冰锥都会命中十字。线段未模拟蓄力后撤、飞行速度或碰撞。游戏内预览仍受 `PreviewSpawnRange` 控制。

实时窗口新增“固定瞄准距离”滑块；“写入属性值”同步写入第五项 `AimDistance`，预览用的瞄准角度仍不写回。新增此属性是一次结构变更，尚不等于运行中的游戏已接受 Hot Reload；之后改变其 getter 返回值属于方法体调整。本次保留用户的 0 / 109 / 138 / 60 范围和关闭游戏范围框的选择。

生成器同时提取正式 `GetShotDirection` 以及发射节点中的速度表达式。检查覆盖真实鼠标距离 10 / 100 / 600 / 2400、多个瞄准方向及出生点；断言距离不改变角度、速度仍为 35、固定距离可调、偏转上限不变，并确认旧真实鼠标算法不能通过距离无关检查。新版构建使用单独的 `ice-spawn-aim-preview` 目录，旧窗口可以继续运行，未保存的参数不会因构建而丢失。
