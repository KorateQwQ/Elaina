运行 `powershell -NoProfile -ExecutionPolicy Bypass -File Tools/IceCycleChecks/run.ps1`。

先仅编译KL与伊蕾娜（不打包、不关闭正在运行的游戏），随后针对真实编译程序集和tML实体检查：每批攻击返还、共享锚点去重、冷却归零/不储存、玩家归属、36次冻结门槛、冻结奖励与间隔、范围判定、正式JSON预算和双语HJSON解析。

冰凌锁追踪/分段版本另检查：真实视觉单元抵达和随目标平移、晚到状态重建、NPC槽位复用、独立冰封与冻结系统隔离、免疫目标和整个关联组、溅射目标不受控、多人叠加解除、提前销毁清理。真实控制器AI运行111帧，仅拦截`Projectile.Damage`世界扫描以记录每次脉冲，验证15次80像素AOE＋一次200像素终爆及50/50精确整数预算；不替代真实防御/免伤结算。

隔离宿主通过反射构造玩家/NPC组件，不加载世界、角色存档、渲染器或网络连接。不能替代实际弹幕命中、技能切换、视觉和双人联机测试。生成文件在`.vissandbox/ice-cycle-checks`，测试源用`.cs.txt`，不进入正式编译。

追加检查：目标在第1/45/100帧死亡或槽位复用后继续完成16次伤害脉冲，脱离状态网络序列化；冰元素tag在单机/服务器/客户端处理分支均不隐式添加积蓄；各攻击通过自己的`FreezeBuildup`独立提交2.8/7.5/0点，0点不会抹除已有进度。这里测试实际处理方法与序列化，不使用真实网络连接。

独立施法检查调用正式魔杖与技能玩家入口，只拦截冰凌锁创建动作/弹幕的边界：验证可装备并占用技能槽、选中后左键释放、不提供右键派生、独立扣费/充能/急速、失败不消耗、切换技能后正常恢复，以及原有减 CD 仍作用于同一实例。选中冰锥或冰凌锁均启用同一准星，两者统一排除无敌、不可追踪及友方目标。原有冰封控制层仍单独验证命中后不受免疫影响，不代表这些目标能被施法索敌选中。
