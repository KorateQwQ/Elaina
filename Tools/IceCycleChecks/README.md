## 2026-11-08 附着去重移到发起端

问题：水流术、水球命中正常出伤却不积蓄潮湿。KL 服务器侧按 `(玩家, 弹幕类型, projectile.identity)` 记录脉冲序号，`identity` 即会被复用的弹幕槽位；新一次施法序号从头计数（水球固定为 1），复用旧槽位时整段积蓄被当成重复包丢弃，记录 30 秒才过期。

## 冰锥术竖直瞄准回归（2026-11-08）

运行 `& ./Tools/IceCycleChecks/run.ps1 -IceActionOnly`。使用正式编译的 `Action_IceCone`、`ShootActionNode`、`AnimAction.ShootFromAction` 与真实 tML Player；仅固定准星/施法条件、跳过外部物品钩子，并在 `CombinedHooks.Shoot` 处截住世界弹幕分配。通用发射函数中的转身逻辑完整执行，不用模拟转身替代。

问题是冰锥的轻微弹道修正会在竖直瞄准附近产生正负水平速度，`ChangePlayerDirectionOnShoot` 随之覆盖动作朝向。原实现先设置姿势再发射：首枚之后错误朝向进入魔杖旋转计算，保持期间则留下朝向与手臂/魔杖不一致的状态。修复在两条发射路径之后重新应用瞄准姿势和物品旋转。

覆盖上下及两侧附近、左右瞄准、两种重力方向、首次节点、保持期间连续发射和收势。修改前在正上方首次发射即失败；修改后 1,920 次实际发射回调通过，其中 696 次子弹速度朝向与瞄准朝向相反，共 9,617 条断言通过。此回归不生成真实弹幕，不验证伤害、联机和完整游戏绘制；外观入口见 `Tools/WaterLaserPreview/README.md`。源码编译通过，尚未游戏内验证。
