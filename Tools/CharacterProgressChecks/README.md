# 角色 Boss 进度与等级上限回归检查

运行本目录的 `run.ps1`。脚本先编译 KL 和伊蕾娜的 Debug DLL，再直接测试实际程序集；只编译及复制 DLL，不打包模组、不关闭或重载游戏、不读写真实角色存档。

覆盖以下行为：
- 外部 Boss Checklist 列表为空时，使用 KL 原版备用表。
- 预览提示不修改角色；点击更新 Progress、ProgressSet 和对应等级上限，但不增加当前等级或清空经验。
- 提示实时切换到下一个 Boss；相同 progress 与身体分段不重复推进。
- 外部列表按进度排序，忽略事件；存在外部列表时不混入原版 fallback 的进度坐标。
- 重置、最终阶段、存档内存往返和角色隔离。
- 升满级读取当前上限并清空升级时的经验，重复调用不推进 Boss 记录；提高上限后可以再次升满，内存存档往返保留等级。
- 正常升级及调试升级每级发 20 研习点，每逢 5 级额外发 20 点；调试增加上限提前补齐到新上限。检查跨级、封顶暂存、真实 Boss 解锁后消化暂存经验、提前发点后正常升级不重复、余额与结算记录存档往返、旧存档只追补本次平衡差额、角色隔离和整数饱和。
- 世界击杀查询委托设为抛出异常，确保推进逻辑不依赖世界进度。

测试通过反射填充独立测试进程中的 Boss 表和本地化名称，不代表已在游戏中验证按钮交互或视觉。小数 progress 仍沿用 KL 的 GetLevelCap 映射，因此部分相邻 Boss 的等级上限可能相同。
