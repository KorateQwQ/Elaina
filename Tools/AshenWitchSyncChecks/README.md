# 被动技能同步与护盾边界检查

运行（PowerShell 7）：`pwsh -File Tools/AshenWitchSyncChecks/run.ps1`

脚本先编译 KL 与伊蕾娜，再使用实际编译程序集执行无游戏窗口的集成检查。

- `SkillSyncPlayer` 集中同步灰之魔女与魔力护盾的学习/开关状态，各端重新计算生命上限并限制负生命恢复。
- 保留 KL 的 RPC 实例查找、反射调用、参数序列化、服务器转发与接收逻辑。
- 仅替换 `ModPacket.Send`，通过内存队列模拟一个服务器和三个客户端；不是实际 socket 或游戏内联机测试。
- 覆盖首次加入、开关变更、中途加入后的已有状态补发、未学习/撤销学习、独立技能实例及单机无网络开销。
- 检查各端生命上限、生命裁剪、`LostMaxLife`、独特魔力上限与魔力模式。
- 检查魔力护盾的开启、关闭、撤销学习及中途加入补发；各端无需同步魔力即可清除负生命恢复及负累计值。
- 检查状态不变时不重复发包，不会产生应答循环，且灰之魔女关闭后各端护盾随前置条件失效。

魔力护盾的直接受击、实际生命恢复 IL 钩子及本地/远端资源消耗边界另见 `Tools/MagicBarrierChecks`。护盾生效时负生命恢复归零，不消耗魔力；普通受击仍仅由受击方结算减伤与耗魔。
不修改 KL RPC、身份同步、技能 UI 或存档格式。开关继续保持原有“不存档”的语义。
