### ImproveGame 蜂蜜面包无限增益兼容（2026-10-22）

ImproveGame 的 `ApplyBuffItem.GetItemBuffTypes`（旧版为单数 `GetItemBuffType`）按物品类型缓存增益，且无限增益直接添加 Buff，不触发蜂蜜面包的 `OnConsumeItem`。因此会遗漏开心，并可能沿用其他角色缓存的饱食等级。`ImproveGameFoodCompatibility` 识别新旧两个入口，在该查询返回非空时，将蜂蜜面包的结果按本地接收者解析为伊蕾娜的很满意＋开心，或其他角色的吃得好；不修改共享物品或原缓存。固定 ID 的 `AddPotion` 接口无法表达角色条件，因此使用可选运行时钩子，不增加 ImproveGame 硬依赖。成功挂接时在客户端日志记录实际版本和入口名称。
