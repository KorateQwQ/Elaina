操作

  • 滚轮 / 数字键 1–8 / 点击：切换当前技能
  • Z：释放当前技能；封印中的技能会被拒绝
  • X：推进当前技能的解封条件
  • 冰凌锁初始为「冷却中 + 封印」，魔力护盾为「仅封印」
  • 对冷却中或有层数的技能点「封印此技能」可查看叠加态

解封条件为演示数据：冰凌锁「冻结敌人 3 次」、魔力护盾「开启灰之魔女」。字体使用本机的思源宋体 / Noto Serif SC（缺失时回退到系统衬线体），与游戏内的 NotoSerifSC 动态字体可能有细微差异。这是浏览器预览，不是游戏截图。
