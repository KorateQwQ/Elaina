# 霜幕：功能与临时特效

霜幕使用现有 `FrostVeilSkill.png`，自动注册进技能系统，星图默认位置为 `(700, 590)`，并显示冰锥术前置关系。解锁需要冰锥术 Lv.13，保留通用技能点/木材消耗。JSON 中原 `CustomSkill2` 已改为 `FrostVeilSkill`，数值保持原样：当前消耗50魔力、基础冷却60秒；等级成长沿用该行配置。伤害预算、冻结积蓄、命中数等攻击字段不参与霜幕效果。

冰凌锁的解锁条件为冰锥术达到 Lv.19，且世界已击败霜月女王（`NPC.downedChristmasIceQueen`）。当前成长配置下，花后角色等级上限 Lv.65 对应冰锥术满级 Lv.19。冰锥术保留阶段门槛与通用消耗，首次学习额外消耗1个原版寒霜核，不改变升级材料。

霜幕施放时，为自己及800像素内存活、同队、非PvP的玩家各赋予3层护盾；双方队伍均为0也视为同队，与现有治疗/回城一致。每名玩家只持有一组霜幕，重复施放重新补满并刷新，以新施法者的强度替换。离开范围后仍保留已经获得的护盾。

每层强度为施法当时伊蕾娜 `MaxMagicPoint / 20`，包括魔力护盾相关的最大魔力加成；之后换装备或施法者离开不会改变这组护盾。受击先执行原有魔力护盾百分比减伤与扣魔，再执行霜幕固定抵消，每次实际受击最多消耗一层。固定抵消后的伤害向下取整；完全挡住时取消本次伤害并提供正常的最低受击无敌时间。部分抵消在实际 `OnHurt` 时才扣层，避免原版闪避仍扣层；魔力护盾已完全抵消的攻击不再消耗霜幕。持续掉血不属于直接受击。

每轮3600帧（60秒）结束时，只要还剩至少一层，就免费补到3层并重新开始3600帧；可以连续续期。三层耗尽后不会自行复活，需再次施放。死亡和重新进入世界会清理霜幕。自动续期不消耗施法层数、魔力，也不重置技能冷却；基础冷却仍通过已有技能框架受急速影响。

## 后续修改入口

- `ElainaModSkills/Skills/Ice/FrostVeilDrawing.cs`：临时冰晶护盾的绘制，唯一视觉入口为 `Draw`，可直接替换。
- `FrostVeilProjectile.cs`：每个受保护玩家拥有一个无伤害弹幕，跟随玩家并绘制当前剩余的1至3个护盾；弹幕由该玩家客户端生成，走原版弹幕同步。
- `FrostVeilPlayer.cs`、`FrostVeilState.cs`：层数、寿命、固定减伤、死亡清理；数值不依赖视觉弹幕是否成功分配。
- `FrostVeilSystem.cs`：施法范围常量 `CastRadius`、服务端选取友方及同步。施法者发送强度快照，受击玩家结算自己的消耗和续期，服务器转发状态；每次重施递增代号，避免在途旧状态覆盖新霜幕。后来加入的玩家通过 `SyncPlayer` 获取状态。
- `MagicBarrierSkill.MagicBarrierModPlayer.ResolveDirectHit`：明确按魔力护盾、霜幕的顺序调用，不依赖两个 ModPlayer 的加载顺序。
