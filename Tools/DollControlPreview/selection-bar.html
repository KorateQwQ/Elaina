玩偶选区操作条 · 样式方案

按炼金手记 / 技能手札现有的视觉语言重做：颜色与部件直接取自 AlchemyDrawing（Ink / Muted / Lavender / Gold / LineColor、Frame、CornerBrackets、RoundRect、Spark），主按钮即 CraftButton 样式，次按钮即 DebugButton 样式。无动画。逻辑像素按 100% UI 缩放绘制，鼠标悬停可看 hover。

与现状相比

  • 去掉强调色顶条、实心色块按钮和紫色粗边框，改为手记同款的细线框 + 四角折线，整体与炼金 / 技能界面同一套颜色。
  • 工具色（琥珀 / 蓝）只留在世界里的选区标记上；操作条统一用 Gold 作为“执行”色，和「炼制」按钮一致。
  • 数量按 {0} 拆开：标签用无衬线 Muted 小字，数字用衬线 Ink 大字，与「已研究 20 / 23」的写法一致。
  • 禁用态沿用 CraftButton 的整体 40% 透明度，不另造灰色按钮。

实现要点（选定后再改 C#）

  • 直接复用 AlchemyDrawing 的 Box / Frame / CornerBrackets / RoundRect / Spark / Text，字体衬线用 NotoSerifSC、小字用 HarmonyOS Sans SC。
  • 布局仍由 GetLayout 统一给出面板与按钮矩形，输入命中逻辑不变。
