# 实白主线与半透明细节

造型基准仍为初始 DollControlSkill.before.svg，保留猫咪的少量尖耳、短胡须和猫嘴微调。上一版整体半透明版本保存在 before-line-hierarchy。

参考用户提供的两张 56×56 图，它们都只使用 255、104、0 三档 alpha。半透明用来表现内层结构和局部阴影，并非按上下位置给全部轮廓分档。此次改为：

- 实白 alpha255：主要外轮廓、八只原版眼睛、鼻子、关键嘴线及星芒。
- 半透明 alpha104：内耳、犬耳折面、被前景遮挡的颈部、口鼻边框、胡须、悬丝及辅助轨迹。
- 全透明 alpha0：大面积面部留白与背景。

保持原版猫眯眼、犬点眼、兔熊错位叉眼的像素位置。半透明线和小块按语义区域指定，不做全图降亮，不添加模糊或预烘焙辉光。

生成器保存完整 alpha 网格，并输出一一对应的 SVG/PNG。检查原尺寸、放大、翻转、深浅背景及相同参数模拟 Bloom。对照图同时保留初始原版造型比较和上一版半透明线条比较。
