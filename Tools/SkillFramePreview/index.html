技能节点边框魔女手札 · 星图节点重设计

旧版：术式 = 旋转 45° 的四角括号，心得 = 方形四角括号，两者轮廓接近、层次单一。
新版思路：用轮廓区分类型，用细节区分状态。术式是“星盘纹章”——八角窗 + 四向星芒，主动、锐利； 心得是“月相铭环”——圆环 + 新月 + 刻度，被动、沉静。所有元素均可用现有 Line / Dash / Ring / Image("Glow") 绘制，无需新贴图。

设计说明

术式 · 星盘纹章

八角窗（半宽 29，切角 8）承托图标，内嵌一圈 4px 内缩细线作双线描边； 四向星芒从窗边伸出，上芒最长并带一颗菱形宝石，指向“施放”；下芒最短，正好吊住等级铭牌，形成挂坠感。 对角线上的 4 条短刻度补全八向星形。
满级：星芒内部填充金色；选中：外圈点状星环缓慢旋转 + 顶部十字星。

心得 · 月相铭环

圆形双环（R 36 / 32）与术式的尖锐轮廓形成第一眼可分辨的对比； 左上一道 新月 象征“领悟”，右下三颗由小到大的 月相点 随等级逐个点亮； 外圈 30° 一格的星盘刻度在新月处断开。
心得不可装配，因此不显示装配号，也不需要“施放”方向的星芒。

移植到 ConstellationDrawing

全部基于直线 / 弧线，可直接替换 DrawNode 中的 Corners 调用。需要补两个小原语： 
// 闭合折线（八角窗、星芒、六边形）
void Poly(Vector2 c, Vector2[] pts, float s, Color col, bool closed = true)
// 圆弧（新月、刻度断开的环）
void Arc(Vector2 c, float r, float a0, float a1, Color col, int seg = 24)
所有尺寸乘 _zoom，线宽保持 1px（与本页 non-scaling-stroke 一致）， 旋转点环用 ConstellationUIClock 的时间驱动角度即可。
