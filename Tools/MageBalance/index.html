普通攻击设计 · 直接按目标 DPS 定价

每个普攻独立设置倍率、整次耗蓝、动作时长和发射数量。动作时长按连续施法的完整周期定价，不读取游戏动画；3 发表示同一目标预期吃到的 3 次等额命中，不是每发各领一份整次伤害。

参考普攻名称 / ID目标 DPS / B倍率曲线 ⓘ整次耗蓝动作时长 / 秒每次发数裸装 DPS整次基础伤害每发基础伤害每秒耗蓝每蓝价值 ⓘ每蓝伤害（当前配装）ⓘ操作

整次伤害 = B × DPS 倍率 × 动作时长；每发伤害 = 整次伤害 ÷ 发数。填写倍率曲线后，倍率按该技能等级对应的角色等级插值（例如“1:1, 10:0.9, 50:0.6”），超出两端取端点；配装/续航区按当前 B 反推等级取值。蓝耗单独定价，不反向决定普攻伤害。普攻每蓝价值 = 倍率 × 动作时长 ÷ 整次耗蓝 ÷ (基准循环增幅% / 100 / 20)，乘 B × 基准循环增幅% / 100 / 20 × 普攻装备倍率即为当前配装每蓝伤害；技能每蓝净伤害还扣除了占手损失。零耗蓝显示“无消耗”，基准增幅为 0 时每蓝价值无法折算，显示“—”，每蓝伤害仍可查看。上方配装/续航区一次只使用一个参考普攻，不把多个普攻的 DPS 叠加。保存后所有条目均可由 C# 按 ID 读取。发数必须与技能实际命中数对应，配置不会自动生成弹幕或修改动画。

名词说明（鼠标悬停表头 ⓘ 也能看到）
每蓝价值 = CD × CD伤害折算率 × K
每花 1 点蓝换到的额外伤害（乘 B × 0.002 × 装备倍率就是伤害值）。蓝耗大小不改变它；占手时长不计入它，读条时少打的普攻（扣除占手补偿后）在“每蓝净伤害”中扣除。命中率低于 100% 会扣减，表中“每蓝净伤害”已扣。K 统一时，CD 越短的技能每蓝越不值钱。
蓝需求 = 蓝耗 ÷ CD
CD 一好就放时，这个技能每秒吃掉多少蓝。它决定技能“能吸多少蓝”，与它“每蓝值多少”是两回事。
宽 / 窄
宽：蓝需求 ≥ 技能可用蓝的 50%，余蓝再多也消化得了，适合当“蓄水池”，奥秘多出来的蓝就靠它变成伤害。窄：蓝需求 < 15%，奥秘和增伤都很容易放满，主要抬升整体强度，几乎不拉开两者差距。中：介于两者。
技能可用蓝 / 秒
回蓝 − 普攻每秒耗蓝 − 受伤损蓝每秒 + （开场蓝 + 全部药剂）÷ 战斗时长。普攻优先，剩下的才轮到技能。
阶梯与边际技能
把技能可用蓝按顺位从高到低“倒”进技能，每个技能最多吃到它的蓝需求。蓝在哪一级用完，那一级就是边际技能：多出来的蓝（例如奥秘带来的）都流向它，所以奥秘的收益由边际技能的价值决定，而不是由最强的技能决定。
盈亏线
把一个饰品从增伤（按当前伤害与暴击取险恶或幸运中更高的一个）换成奥秘刚好打平时，边际技能需要的每蓝价值。边际技能 ≥ 盈亏线 → 奥秘占优；低于 → 增伤占优。回蓝百分比越高、战斗越短、药越多，盈亏线越低；普攻越强、其他伤害越多，盈亏线越高。
溢出
全部技能按 CD 放满后蓝还有剩。多出的魔力没有去处，奥秘必然落后。解决办法：加一个宽的、价值高于盈亏线的技能当蓄水池，或提高现有技能的蓝耗。
新增技能会怎样
价值高于边际技能：拿走低价值技能的蓝，DPS 上升；蓝变得更紧缺，奥秘优势变大。价值低于边际技能：节约型打法下基本不放，DPS 不变；按优先级打法时如果排在前面，会抢走高价值技能的蓝，DPS 反而下降，此时不如一个无消耗的 buff。蓝溢出时：任何正收益技能都有用，宽的最好。
局限
这是稳态估算，按“蓝先给价值高的技能”的理想打法计算；“按优先级”策略实际按优先级花蓝，以上方实际模拟次数为准。盈亏线按当前配装估算，通常略偏保守（实测奥秘打平所需的价值略低）。短战斗主要在花开场蓝，阶梯只作参考。

技能等级成长区间

角色等级只决定技能可升到哪里

“解锁阶段上限”区分初始 1–5 级阶段与史莱姆王后 6–10 级阶段，不是必须练到阶段上限才解锁。“首级角色等级”定义技能 Lv1 的角色门槛和伤害基准。飞弹默认 5 / 1，冰锥示例默认 10 / 6；如果想让冰锥必须角色 10 级才开放，可把首级改为 10。每阶段 2 次升级不含解锁自带的 Lv1。“解锁时期”是快捷选项：第 k 个时期（击败对应 Boss 后）写入上限 5k、首级 5k−4；手填非 5 的倍数时显示为自定义。切换参考配装会把预览角色等级设为该时期上限，并只启用此时已解锁的主动技能。

成长方式可逐技能选择：“按阶段成长”沿用公共阶段跨度；“固定等级间隔”从首级角色等级起，每隔指定角色等级新增 1 个技能等级，与公共阶段跨度及每阶段新增数量无关。例如角色 1 级解锁、间隔 10：Lv1→1、Lv2→11、Lv3→21；间隔 7：Lv1→1、Lv2→8、Lv3→15。解锁时期仍用于设置首级门槛与阶段标记。

配装与属性配置 · 按 Boss 阶段

随 SkillBalance.json 保存 · 游戏内按 L 打开快捷配装

每个阶段一套伊蕾娜推荐配装与角色属性。实验室切换阶段时读取这里的护甲、饰品、槽位、伊蕾娜前缀、原版对照前缀与基础魔力；实验室里的临时改动不会写回此页。游戏内按快捷键（默认 L，可在“控制”中改键）选择 Boss 阶段即可一键换装：删除当前功能护甲与饰品，再按预设生成带前缀的新装备，空槽也会清空，不取用或写入背包；基础魔力与最大生命直接设为本阶段数值，可升可降。仅单人模式可用，第 6、7 饰品槽需要专家／大师模式。

默认按专家模式、伊蕾娜扫帚承担机动、兼顾输出与生存选择；开局是低资源起步，其后允许在已解锁阶段刷齐材料，不要求刚击杀就立即拥有。钛金世界用钛金套，精金世界可选精金法师套；猩红世界可把蠕虫围巾换为混乱之脑。首只机械 Boss 后可重复刷神圣锭，三王后才推荐天界徽章；花后冰冻护盾适合 Boss 战，十字章护盾保留为探索选项。原版手铐受伤回蓝不视为伊蕾娜特殊魔力回复。逐阶段依据与源码核对
