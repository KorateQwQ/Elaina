# 水流主导减CD：0.16秒 / 水球4秒

2026-10-14。用户认可此调整方向后，以第三轮状态模型重测；300秒、不受击、五瓶30%药剂，正式配置未修改。

本次只改变水流每次实际命中减CD为0.16秒，水球每次实际命中减CD为4秒。冻结基础CD60秒、CD后冰锥至少3秒、冻结4秒和其他伤害/耗蓝参数都保持第三轮推荐。

## 分工验证

| 全奥秘正常循环，完整冻结间隔统计 | 原先0.1333 / 6秒 | 候选0.16 / 4秒 |
|---|---:|---:|
| 水流平均每轮减CD | 17.68秒 | 21.38秒 |
| 水球平均每轮减CD | 12.00秒 | 8.00秒 |
| 水流占总减CD | 59.57% | 72.78% |

水流已从约60%提升到约73%的减CD贡献，水球仍能一次推进4秒，并提供伤害和潮湿。

候选正常循环冻结间隔34.10、33.30、33.30、34.85、33.30、33.30、33.30、34.10秒；最快水系速度校准约33.30秒，包含随后3秒冰锥积累。约30秒是CD阶段的结果，不是引擎硬限制。测试水流0.1秒周期仍能得到小于30秒的完整冻结间隔。

## 输出结果

| 场景 | 全奥秘DPS / 原版倍数 | 全增伤DPS / 原版倍数 |
|---|---:|---:|
| 原先无帽 | 17489.43 / 1.694 | 17619.72 / 1.707 |
| 候选无帽 | 17489.43 / 1.694 | 17999.52 / 1.744 |
| 候选带帽 | 19073.47 / 1.848 | 20521.51 / 1.988 |

同一简单循环奥秘差距：无帽-2.83%，带帽-7.06%。提高水流价值也帮助少放水球的增伤配装追赶冻结频率，因此不能假定此次分工调整对前缀对比完全中性。

双方各自选择所测更高输出规则后：无帽1.694 / 1.800倍，奥秘差距-5.85%；带帽1.848 / 1.988倍，奥秘差距-7.06%。带帽增伤是否超过2倍应以这行结果为准，不能只取参考循环称已完全达标。

## 简单切换是否仍更赚

所有策略CD结束后都至少冰锥3秒，每种CD期普攻倾向分别优化所测资源策略：

| CD期普攻倾向 | 无帽奥秘 / 原版 | 无帽增伤 / 原版 |
|---|---:|---:|
| 持续水流 | 1.694 | 1.800 |
| 冰锥为主，末段水流 | 1.606 | 1.694 |
| 持续冰锥，补潮湿才用水流 | 1.588 | 1.614 |

候选方向保留了用户要求的切换：CD期水系、就绪后冰锥、冻结后引爆。

去掉水流并重新选择所测最高输出规则：1.578 / 1.574倍。去掉水球：1.331 / 1.598倍。两者仍有组合价值，但尚未用其他技能或buff替换空槽。
