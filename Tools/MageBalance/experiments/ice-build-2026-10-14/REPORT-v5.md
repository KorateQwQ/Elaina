# 长冰锥阶段、低切换冰法候选

2026-10-14。独立300秒高血量木桩设计实验；没有改动正式模组或实验室页面。

建议每轮在冻结冷却期间持续水流，冷却就绪后切冰锥，完成14秒有效攻击积累，再接冰凌锁、切回水流。水球和天雷优先在水流阶段施放。期间不需要为了续潮湿反复切回水流。

| 参数 | 候选 |
|---|---|
| 冻结CD、持续时间 | 60秒、4秒；从触发冻结起计时 |
| 冰锥冻结门槛 | 14秒有效攻击，28次完整攻击、84发有效命中 |
| 冰锥积累断档 | 超过2.5秒没有有效命中清零；从旧1.2秒放宽。此实战容错未验证 |
| 水流 | 每次1.5蓝、0.2秒、每次0.18B；有效命中立即减冻结CD0.5秒；潮湿5秒 |
| 水球 | 150蓝、CD15秒、施法1.35秒、8.1B；命中减冻结CD4秒；潮湿15秒 |
| 冰锥伤害 | 每次4.5蓝、0.5秒、3发共0.45B；毕业DPS倍率0.9B |
| 冰凌锁 | 100蓝、CD20秒；3.2B+剩余冻结秒数×2.5B；施法0.2秒消耗冻结、再延迟1秒命中 |
| 天雷 | CD120秒；施法2秒、延迟1秒、离手持续30秒；15蓝/秒、整次450蓝；预算48B |

水流、水球的潮湿只用于天雷锁定；取消v4的1.6倍/2倍冻结CD加速，两套规则不能并用。CD期间冰锥不积累；水系不储存负CD；没有30秒硬下限；相关Boss部位共用冻结CD。冰凌锁消耗冻结不会重启CD。

## 300秒结果

条件：毕业6槽，星云伤害3层；满蓝、不受击；5瓶30%回复药；无额外回蓝桥接。实际弹道命中和受击没有模拟。B为原始基准3500，装备倍率另算。

| 项目 | 无帽全奥秘 | 无帽全增伤 |
|---|---:|---:|
| 水流占手时间 | 129.05秒 | 113.60秒 |
| 冰锥占手时间 | 140.00秒 | 116.87秒 |
| 两种普攻中冰锥占比 | 52.03% | 50.71% |
| 水/冰切换次数 | 19 | 16 |
| 冻结次数 | 10 | 8 |
| DPS/原版 | 1.752倍 | 1.776倍 |
| 戴帽DPS/原版 | 1.954倍 | 1.956倍 |

无帽奥秘差-1.37%，戴帽奥秘差-0.11%。只代表本次固定策略，未证明全局最优或所有前缀配装优劣。

全奥秘相邻冻结间隔：32.9、31.1、31.1、31.1、32.9、31.1、31.1、31.1、32.6秒，包含14秒冰锥积累。天雷实际付费90秒，潮湿覆盖91.20%。

无帽全奥秘伤害占比：water 18.41%，ice 19.98%，ball 21.84%，lock 18.13%，thunder 21.64%。

对照：v4全奥秘水/冰切换76次，本候选19次。CD期间继续冰锥、只补潮湿的对照策略为奥秘1.593倍、增伤1.756倍，均低于本候选，但其他策略未穷举。

只延长旧版冰锥时间、保留水流0.16秒/命中和天雷34B的对照：

| 冰锥积累 | 奥秘冰锥时间占比 | 奥秘DPS/原版 |
|---|---:|---:|
| 3秒 | 10.13% | 1.694倍 |
| 12秒 | 31.24% | 1.527倍 |
| 24秒 | 52.06% | 1.410倍 |

因此14秒门槛需要配合更强水系减CD，不能把本结果归因于只增加冰锥时间。长积累遇到躲避会更难完成，2.5秒断档容错只做了不受击情况下的验证；若实战仍容易清零，可再测试暂停或衰减积累。

验证通过：14s buildup and no cooldown precharge；50-60% ice basic hand time in four graduation cases；at most 20 water/ice switches in 300s；water cooldown rotation beats compared ice cooldown rotation；mana conserved and thunder paid continuously；all four graduation cases within 1.5-2x vanilla；formal configuration unchanged。
