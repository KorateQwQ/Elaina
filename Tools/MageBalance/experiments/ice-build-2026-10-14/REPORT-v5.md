# 长冰锥阶段、低切换冰法候选

2026-10-14。独立300秒高血量木桩设计实验；没有改动正式模组或实验室页面。

建议每轮在冻结冷却期间持续水流，冷却就绪后切冰锥，完成14秒有效攻击积累，再接冰凌锁、切回水流。水球和天雷优先在水流阶段施放。期间不需要为了续潮湿反复切回水流。

| 参数 | 候选 |
|---|---|
| 冻结CD、持续时间 | 60秒、4秒；从触发冻结起计时 |
| 冰锥冻结门槛 | 14秒有效攻击，28次完整攻击、84发有效命中 |
| 冰锥积累断档 | 超过15秒没有有效冰锥命中清零 |
| 水流 | 每次1.5蓝、0.2秒；目标处于冻结CD（含冻结中的4秒）时0.9B、每次0.18B，否则0.7B、每次0.14B；有效命中立即减冻结CD0.5秒；潮湿5秒 |
| 水球 | 150蓝、CD15秒、施法1.35秒、8.1B；命中减冻结CD4秒；潮湿15秒 |
| 冰锥伤害 | 每次4.5蓝、0.5秒、3发共0.45B；毕业DPS倍率0.9B |
| 冰凌锁 | 100蓝、CD20秒；3.2B+剩余冻结秒数×2.5B；施法0.2秒消耗冻结、再延迟1秒命中 |
| 天雷 | CD120秒；施法2秒、延迟1秒、离手持续30秒；15蓝/秒、整次450蓝；预算48B |

水流、水球的潮湿只用于天雷锁定；取消v4的1.6倍/2倍冻结CD加速，两套规则不能并用。CD期间冰锥不积累；水系不储存负CD；没有30秒硬下限；相关Boss部位共用冻结CD。冰凌锁消耗冻结不会重启CD。

## 300秒结果

条件：毕业6槽，星云伤害3层；满蓝、不受击；5瓶30%回复药；无额外回蓝桥接。实际弹道命中和受击没有模拟。B为原始基准3500，装备倍率另算。

| 项目 | 无帽全奥秘 | 无帽全增伤 |
|---|---:|---:|
| 水流占手时间 | 129.05秒 | 113.60秒 |
| 冰锥占手时间 | 140.00秒 | 116.87秒 |
| 两种普攻中冰锥占比 | 52.03% | 50.71% |
| 水/冰切换次数 | 19 | 16 |
| 冻结次数 | 10 | 8 |
| DPS/原版 | 1.751倍 | 1.776倍 |
| 戴帽DPS/原版 | 1.953倍 | 1.956倍 |

无帽奥秘差-1.39%，戴帽奥秘差-0.13%。只代表本次固定策略，未证明全局最优或所有前缀配装优劣。

全奥秘相邻冻结间隔：32.9、31.1、31.1、31.1、32.9、31.1、31.1、31.1、32.6秒，包含14秒冰锥积累。天雷实际付费90秒，潮湿覆盖91.20%。

## 首次运行后的微调

首次运行用2.5秒积累断档、水流固定0.9B。看过结果后改为15秒断档，水流只在目标冻结CD中保持0.9B，其余时间0.7B。其他参数不变。

| 场景 | 首次运行 奥秘 / 增伤 | 微调后 奥秘 / 增伤 |
|---|---:|---:|
| 无帽 | 1.752 / 1.776倍 | 1.751 / 1.776倍 |
| 戴帽 | 1.954 / 1.956倍 | 1.953 / 1.956倍 |

木桩上两项微调几乎不改变结果。推荐循环在冻结CD就绪后一直用冰锥，300秒内只有6次（增伤3次）水流命中落在CD外、按0.7B结算；木桩不躲避，积累从不中断，15秒断档在这里没有被触发。它在有停手躲避的战斗里才起作用，见moon-lord-master-2026-10-14/REPORT.md的断档对照：高压力下2.5秒平均每场清零1～4次，15秒不清零。

0.7B规则的作用是惩罚不放冰锥的打法。不放冰锥和冰凌锁、全程水流时，冻结CD从不启动，水流全部按0.7B结算：奥秘1.369倍、增伤1.582倍；水流固定0.9B时同一打法是奥秘1.517倍。推荐循环比它高27.9%。

验证通过：14s buildup and no cooldown precharge；50-60% ice basic hand time in four graduation cases；at most 20 water/ice switches in 300s；water cooldown rotation beats compared ice cooldown rotation；mana conserved and thunder paid continuously；all four graduation cases within 1.5-2x vanilla；water outside freeze cooldown uses 0.7B; skipping ice and lock is worse；formal configuration unchanged。
