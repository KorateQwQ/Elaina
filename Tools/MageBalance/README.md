# 法师配装成长实验室

独立、离线 HTML 配装与续航工具。主视图是 60 Hz 战斗资源模拟，原先的快速预算保留为辅助定价功能。仅新增分析工具，不修改游戏、KL 或正式技能。

## 使用

浏览器直接打开同目录 `index.html`，无需安装或联网。配置自动保存在当前浏览器，也可导出 JSON，再用页面顶部“导入配置”恢复。导入成功会替换当前配装和参数，并重新计算与保存；请先导出需要保留的当前方案。

1. 选择丛林、精金法师、神圣法师、幽灵面具或毕业星云参考配装。
2. 修改两侧护甲、饰品、前缀和共同裸装 DPS。双方配装各有“全险恶”“全奥秘”按钮，只批量修改该侧当前启用的非空饰品槽，不更换装备、不影响另一侧或隐藏槽；即时重算并保存。
3. 配置战斗时长、开场魔力、0–5 瓶药剂、回蓝、普攻耗蓝、受伤与缺蓝策略。
4. 配置技能单次蓝耗、CD/充能、占手、延迟、持续伤害、储存次数、首次释放、优先级和命中率。
5. 观察模拟 DPS、首次缺蓝、药剂耗尽时刻、魔力时间轴、每个技能施放次数与资源总账。
6. 需要快速定价时展开“快速预算结果”，使用下方旧预算控件；旧预算不会叠加到模拟输出。

预设是阶段参考组合，不是最优配装推荐。手动配置不做完整饰品冲突和阶段限制校验；同名饰品重复会提示。机动/生存占位不代表所有此类饰品具有相同价值，前缀防御也不等于实际生存能力。

## 固定口径

- 同期原版裸装武器和伊蕾娜裸装普攻采用同一基准，不为主动技能扣除普攻预算。
- 不建模攻速、原版减耗或冷却缩减属性。技能本身 CD 必须参与时序；基准 CD 参与单次伤害定价，不额外重复乘增伤。
- B 已包含裸装暴击期望。装备加成按加法汇总，再乘双倍暴击的期望；暴击限制在 0–100%。
- 技能默认继承装备伤害和暴击，也可关闭此假设。
- 旧预算抵消占手补偿与损失普攻。战斗模拟则逐帧停普攻、结算包含占手补偿的技能总伤害，不会重复给满额普攻。
- 不自动计幽灵追击、多目标、防御、伤害取整、魔力病、补蓝停手或走位损失；特效可手填。

## 旧快速预算公式

百分比采用小数表示：

```text
G = (1 + damage) * (1 + finalCrit) / (1 + nakedCrit)
vanillaDps = B * Gv + vanillaProc
elainaDps = B * autoRatio * Ge + B * (ratePer20 / 20) * E * Gskill + elainaProc
```

默认 `ratePer20 = 0.04`。

预算模式：

```text
source = equipmentAddedMana | totalMana | manualBudget
plannedBudget = max(0, source - reservedMana) * conversionFraction
spentBudget = max(0, plannedBudget - hurtMana)
E = spentBudget * averageQuality
```

**将容量预算映射到技能消耗，是显式的设计假设，并非自动成立。** 默认仅映射配装新增魔力；可切换为总魔力以包含裸装储备。

技能清单模式：

```text
plannedBudget = sum(skillCost * realizationFraction)
retained = plannedBudget > 0 ? max(0, plannedBudget - hurtMana) / plannedBudget : 0
E = retained * sum(skillCost * skillQuality * realizationFraction)
```

兑现率是相对基准循环的实际释放频率与命中比例的乘积。清单不变时，增加最大魔力不会自动增加伤害。技能蓝耗合计不是每秒耗蓝。单次支付超过上限会警告，但仍保留输入的理论结果用于调参，不把其宣称为可实现输出。


## 战斗资源模拟

- 时长 1–600 秒，60 Hz 调度。周期与动作最终按帧判定，存在最多一帧的时间量化。
- 满蓝开场比例可调；默认回蓝 `5 + 0.02 * 最大魔力`，或自定义。只加实际可容纳回复，其他记为溢出。
- 默认 5 瓶药，每瓶上限 50%。行动付款不足时，计算所需药数；若全部药仍不能支付，不提交扣费/用药。成功时补充与扣费同时结算，再裁剪最终余额。
- 单次技能费用超过上限，或费用加主动预留超过上限时，实际模拟跳过并提示。不允许“攒几瓶药施放超过容量的技能”。
- 主动预留只限制技能，普攻与受伤仍可消耗这部分魔力。生命换蓝默认不支持。
- 技能 CD 从施放开始计时，储存按顺序逐层恢复。首次释放时间可推迟奥义，但不阻止储存充能。
- 低优先级数优先。高优先级缺蓝时可以继续其他技能/普攻，也可以停止输出攒蓝。
- 普攻在完整攻击间隔内占手，付费后到动作结束才记伤害。单次伤害为当前普攻 DPS 乘间隔。
- 技能总伤害：当前普攻 DPS × 有效占手 + B × (每20魔力增幅/20) × 单次蓝耗 × CD × K × 技能装备倍率；命中率作用于整次伤害但不减蓝耗。
- 零占手按一帧计算与补偿，避免无限瞬发；占手期间不普攻。伤害从占手结束加延迟后产生；持续伤害均匀分配，战斗结束后不再记伤害。
- 受伤可按全场总量均匀分摊、周期事件或指定秒数事件执行。这里填请求损失，不先扣除恢复。可用魔力不足的部分记录为“防御未承担”，不能变负，也不会触发护盾自动吃药。
- 指定事件格式 `15:100`，每行一条。格式错误或在战斗结束之后的事件会提示。
- 旧预算的兑现率、兑换率、预留、净损失不参与资源模拟。两种模式共享配装、技能启用/单次费用/K、伤害定价率与装备继承开关；模拟有独立命中率和受伤时序。

### 两个模拟结果

“实际”受当前魔力、回蓝、药剂和受伤限制。

“不限蓝参考”只移除资源限制，保留相同时长、CD、动作、优先级、首次释放和命中条件。它不是全局优化器，同一贪心策略在不同资源约束下可能采用不同动作顺序，所以不应将它宣称为严格伤害上界。

### 资源守恒

```text
开场魔力 + 有效自然回复 + 有效药剂回复
- 普攻消耗 - 技能消耗 - 受伤实际扣除 = 结束魔力
```

资源不足的行动不付款、不用药、不造成伤害。日志列出技能、用药、周期/指定受伤与缺蓝等待段；均匀损蓝只展示总账。UI 展示前 120 条事件，导出含完整日志及采样时间轴。

### 限制

这不是游戏运行时。未模拟敌人防御、击退、打断、死亡、多节敌人、生命转魔力、自动脱战回复或受伤暂停回复；手填套装特效作为恒定背景 DPS。普攻不能被技能在动作中间取消，持续伤害采用均匀分布，复杂技能可通过延迟/持续时间近似，但仍需游戏内验证。

旧浏览器配置补入默认模拟参数，不丢失现有配装与原技能费用。导出保留旧 `result` 字段，并增加 `combat.actual`、`combat.ideal` 与 `combat.vanilla`。

## 毕业星云预设与三种强化

新增 `nebula` 护甲和毕业配装预设，B=3500，默认 6 饰品槽（可手动改为 7），双方三种强化各 3 层。保留饰品混搭和前缀一键设置，不宣称此预设是最优解。

来源为本地 tML 2025.06 源码：

- `Terraria/Player.cs:11442–11456`：星云三件合计 +26% 魔法伤害、+16 暴击百分点、+60 最大魔力、−15% 原版魔力消耗、+10% 移速。
- `Terraria/Item.cs:29649–29674`：防御 14+18+14=46。
- `Player.cs:8541–8542`：每层 +15% 伤害，3 层 +45%，和护甲/饰品/前缀伤害加算，不单独乘 1.45。因此套装本体+满层强化提供 +71% 伤害，不是 +26% 后再乘 1.45。
- `Player.cs:16394–16407`：每帧按层数累积计数，每 6 点回复 1 原版魔力，60 FPS 下每层 10/秒，3 层 30/秒。此恢复先于普通魔力回复延迟处理。
- `Player.cs:8514`：每层 +6 lifeRegen；结合 16281 累加与 16302 的每120计数回1 HP，每层 3 HP/秒，3层9 HP/秒（名义增量，不包括特殊减益对生命回复的修改）。

两侧分别设置伤害/魔力/生命强化 0–3 层，提供“三种全满”。仅选中星云套时应用这些层数；更换护甲停用，但保留层数设置。当前模型假设所选强化开场已拾取且全程维持，不模拟随机掉落、拾取距离和持续时间掉层，也不支持穿其他护甲接收队友星云强化的场景。

### 原版蓝和特殊魔力必须区分

星云原版回复写入 `Player.statMana`。当前伊蕾娜 `ElainaAttributeModPlayer.GetMagicPointRecovery()` 仍是固定 5 + 特殊魔力上限2%/秒，未接入星云层数；`ElainaMagicPointModPlayer` 也没有把星云原版回蓝转入特殊魔力。因此毕业预设默认关闭 `nebulaManaBridge`，忠实保留当前行为。

伊蕾娜配装中的“将星云回蓝转为特殊魔力”用于预览未来适配：开启时按每层10/秒加入资源模拟，自然回复总量为基础回复+星云回复；手动回蓝也被明确解释为基础回蓝，避免重复加算。此开关只影响分析工具，未改任何正式 C# 逻辑。

原版已假设持续射击，所以不会因 +30回蓝再次乘输出。生命回复、46护甲防御与移速仅显示，不凭空增加DPS、减少输入的受伤损蓝或自动转生命为魔力。−15%原版减耗不折扣任何特殊魔力消耗。额外伤害继承开关仍控制技能额外伤害是否吃装备/星云伤害强化。

存储兼容：旧配装补入三个默认满层字段（非星云套不生效），特殊魔力桥接默认关闭。结果导出含强化效果与资源模拟 `baseRegen` / `nebulaRegen`。

## 测试

在本目录运行：

```powershell
node test.cjs
node test.cjs --browser
```

第一条执行 90 项公式/时序/资源守恒/边界/静态测试，只需 Node。第二条额外用隔离的 Chrome 无头会话验证预算和清单、预设、槽位、复制、保存、导出、重复装备警告、移动端溢出与 JS 异常，不访问用户浏览器配置。

## 旧预算：受伤损蓝敏感性

“受伤净损失魔力”默认 0。填写同一技能预算口径内、没有由额外回复补回的净损失；不是扣最大魔力，也不是每秒损失。先处理预留/兑换率，再从计划技能蓝量扣除受伤净损失。清单模式按预计耗蓝等比例削减各技能，属于近似敏感性分析，不模拟不同 CD 下的具体释放优先级。

显示受伤前输出、因受伤损蓝减少的 DPS、剩余技能蓝量。超过预算时技能额外输出最低为 0，不继续削减普攻、特效、魔力上限或自然回蓝。若兑现率已包含受伤影响，此项应为 0，避免重复扣除。旧浏览器配置自动补入默认 0，不清空原有配装。

## 导入和 Git 同步

点击“导入配置”选择之前“导出当前试算”生成的 JSON。支持完整导出文件与 version=1 的纯配置对象；旧版缺少战斗/星云设置时自动补入默认值。文件限制20 MB。不会信任文件中的旧计算结果，所有伤害和时间轴重新计算。字段、版本、数值范围或 JSON 错误时保留当前配置，不写入浏览器存储。

要通过 GitHub 跨电脑保留方案，将导出的 JSON 放进仓库并提交。另一台电脑拉取后打开本页并导入该文件即可；仅提交 HTML 不会带走浏览器 localStorage。导入在本地处理，不上传文件，也不自动修改仓库里的 JSON。
