# 默认配装核对（2026-10-18）

## 版本与适用条件

依据本机实际 `D:/Steam/steamapps/common/tModLoader/tModLoader.dll`（Terraria **1.4.4.9**）和本地 `D:/泰拉原版贴图与代码与其他工具/tModLoader/Terraria/` 源码。网上 Wiki 用于核对获取路线；新版本 Wiki 的属性变化不直接套用到本机。

默认是**专家模式、伊蕾娜扫帚承担机动、Boss 战兼顾伤害／魔力容量／生存**。开局按低资源起步，其后按该阶段已经解锁的内容准备装备，允许刷材料和重复挑战已击败的 Boss。不是每个 Boss 都强行换一档矿石。角色基础生命、魔力与早期前缀数量仍是实验室的成长基准，不是该阶段能达到的上限。

无条件“唯一最强”并不存在：伤害前缀与奥秘取决于技能耗蓝，护盾与减伤取决于受击，幽灵追击取决于弹幕命中，混搭也有不同取舍。以下是有明确依据的通用默认，备选仍在下拉框中。

## 默认路线

| 阶段 | 默认护甲 | 选择与获取依据 |
| --- | --- | --- |
| 1 开局 | 木头盔＋紫晶长袍＋木护胫 | 常规采集、宝石和丝绸起步；不把稀有 Tim 掉落或旅商库存当作开局标配。长袍不阻止护腿提供属性。 |
| 2–3 史莱姆王／克眼后 | 丛林套 | 丛林材料制作，没有 Boss 解锁条件；6% 魔法伤害、12 暴击、80 魔力，适合已经开始探索的法师。 |
| 4–7 世界邪恶 Boss 后至肉前 | 丛林套 | 继续保留容量、暴击和防御；伊蕾娜技能不使用太空枪，陨石套的太空枪免耗不是默认选择理由。魔法帽＋钻石袍＋陨石腿可另选，需旅商物品且牺牲部分防御。 |
| 8–9 血肉墙／史莱姆皇后后 | 钛金法师套 | 肉后已可获取三阶矿，没必要等双子或毁灭者。100 魔力、23% 魔法伤害、13 暴击。精金世界可改精金法师套（80 魔力、20% 伤害、19 暴击）；钛金碎片近身触发不计入静态 DPS。 |
| 10–12 双子后至三王后 | 神圣法师套 | 已击败第一只机械 Boss，可重复刷神圣锭凑齐整套；100 魔力、19% 伤害、19 暴击，保留神圣保护。三王全灭不是神圣套的门槛。叶绿、神圣／叶绿／学徒混搭仍可选择，但不保留神圣保护。 |
| 13 世纪之花后 | 幽灵面具＋长袍＋裤 | 花后地牢灵气制作，完整输出套；25% 伤害、17 暴击、60 魔力，并保留幽灵追击。不是降低魔法伤害的幽灵兜帽。 |
| 14–18 石巨人后至月前 | 完整输出幽灵套 | 通用移动施法默认保持完整输出套；暗黑艺术家装备是石巨人后酒馆老板／撒旦军队路线备选，偏哨兵或混搭玩法，不能将它的哨兵收益直接算给普通法术。拜月后尚无夜明锭，不能提前给星云套。 |
| 19 月亮领主后 | 星云套 | 星云碎片与夜明锭制作；静态26%伤害、16暴击、60魔力，强化球层数另算。 |

饰品安排：

- 伊蕾娜的帽子占实际饰品槽，保留其魔法伤害／暴击／特殊魔力；扫帚可用10木材、20干草制作，不另外用翅膀和鞋占默认槽。
- 早期星力手环，邪恶 Boss 后默认魔力再生手环，提供20魔力。魔法手铐／天界手铐也有20魔力，但它们的受击回蓝写入原版魔力，当前特殊魔力代码没有因此恢复特殊魔力，不能臆算为特殊回蓝收益。灰之魔女关闭时，手环的原版回蓝有效。
- 世吞后蠕虫围巾；这是一条专家腐化路线。猩红世界手动选混乱之脑，普通模式选其他不重复的饰品。不会因为调试生成物品就声称所有世界都能按同样路线获得。
- 骷髅王后黑曜石护盾（地牢钴护盾），肉后十字章护盾；肉后再生手环升级神话护身符，兼有治疗药水冷却收益。
- 肉后巫师徽章。复仇者徽章需要三王各5魂，天界徽章由复仇者徽章升级，默认到阶段12才使用。天界徽章替代手铐的拾取范围功能也不能视为额外特殊回蓝。
- 花后冰冻护盾：圣骑士护盾＋冰冻海龟壳；保留免击退、6防御，半血以下25%减伤，适合Boss战。十字章护盾的减益免疫更偏探索，仍保留选项。灰之魔女减生命上限与“低于当前最大生命一半”不是同一个条件，不假设减伤常驻。
- 石巨人后毁灭者徽章／天界壳：石巨人之眼、日曜石来自石巨人，天界壳另需日食掉落及月光护身符。不会在花后提前推荐。第七个备用槽为大师模式手动启用。

本地源码交叉核对位置（方法名／物品ID比行号稳定）：

- `Terraria/ID/ItemID.cs`：`AdamantiteHeadgear = 400` 是法师头，`AdamantiteMask = 402` 是射手头。完整精金和禁戒混搭两处均修正。
- `Terraria/Player.cs`：`GrantArmorBenefits`、`UpdateArmorSets`（魔法属性、套装效果）、`ApplyEquipFunctional`、`UpdateEquips`、`GrantPrefixBenefits`。头400增加80魔力、12%魔法伤害、12魔法暴击；头402增加远程属性。
- `Terraria/Recipe.cs`：神圣头558消耗神圣锭；天界徽章2220需要复仇者徽章935，935配方包括548／549／547各5份；神话护身符860由49＋535合成；冰冻护盾3997由938＋1253合成。
- `Items/扫帚坐骑.cs`：实际扫帚配方；`Items/accessories/ElainaHat.cs`：帽子属性。
- `ElainaAttribute/ElainaAttributeModPlayer.cs`：原版最大魔力转换为特殊魔力容量；`ElainaMagicPointModPlayer.cs`：灰之魔女模式的回复与消耗入口，不把手铐自动当成特殊回蓝。

## 可重复验证

运行 `./run-loadout-checks.ps1`。脚本先编译模组，再从网页实际表导出测试数据，用当前tML创建物品并应用真实属性和套装效果，逐项对照全部可选护甲与原版饰品的魔法伤害、暴击、魔力。独立检查精金两个映射、神圣保护和完整幽灵输出效果，避免只验证“键名存在”。

同一集成测试检查19阶段实际生成、奥秘收益、锁定／大师槽、空槽、重复项、无前缀、从后期切回早期清空残留、背包不动和时装不动。`node test.cjs --browser` 验证默认路线、获取门槛、旧缓存迁移、自定义配装保留和网页交互。

快捷配装是删除后重建的调试操作：清空当前 `armor[0..9]`，按预设槽序生成。法袍缺腿、无护甲、空槽及旧utility占位均清空，不回收、不读背包、不掉落。不会删除背包、时装、染料、坐骑或其他配装栏。
