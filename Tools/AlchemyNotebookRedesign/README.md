# 炼金手记改版预览

`index.html` 是炼金手记（`ElainaModAlchemy/UI`）的改版样稿，目标是与魔女手札（`Tools/SkillPanelRedesign`，已接入游戏）共用同一套设计语言。本文件记录已定稿的决定与正式接入时要改的地方。预览只是样稿，游戏代码尚未改动。

## 打开预览

`.claude/launch.json` 中的「炼金手记改版预览」在仓库根目录起 `python -m http.server 5542`，打开：

`http://localhost:5542/Tools/AlchemyNotebookRedesign/index.html`

URL 参数：

| 参数 | 作用 |
| --- | --- |
| `?sel=<条目 id>` | 初始选中条目（`mana`、`bread`、`moondew`、`featherlight`…，见脚本里的 `R`） |
| `?lang=en` / `?lang=enRaw` | 英文检查：建议词条 / 现有词条直译（只覆盖卡片与页签；标题与右栏详情仍是中文） |
| `?researched=all` | 全部条目视为已研究，用来检查长名字排版 |
| `?stamp=ribbon` / `?stamp=star` | 切到落选的「可制」方案（丝带 / 角星）对比 |
| `?paper=night` | 夜色纸卡对比 |

左下角按钮同上：纸色、六种示例状态轮换、可制标记、语言。

条目、名称、描述、效果、配方来自 `AlchemyCatalog.cs` 与 `zh-Hans/en-US_Mods.伊蕾娜.UI.hjson`；**炼金等级门槛、背包数量、成品持有为示意数据**，不代表平衡。`vanilla/` 下 21 张原版素材图标从 terraria.wiki.gg 下载，仅供预览，游戏内照旧用 `Main.GetItemDrawFrame` 读贴图。

## 已定稿

- **纸卡：月白**（比现版浅色纸压暗一档，`body.moon` 一组色值）。夜色纸只作对比。
- **「可制」标记：题签。** 去掉右上角圆形印章；卡片说明行只写状态——可研究「◆ 可研究」、可制「✦ 可制」，其余留空。卡片上不再显示每批数量和持有数（右栏都有）。中英文都不缩字。
- **显示稀有度**：详情名字下的小字行「No.xx ◆◆◇◇ 精良」。数据已有（`AlchemyCatalogRecipe.Rarity` / `RarityName`，本地化 `Catalog.Common / Fine / Rare / Exotic` 已存在），之前界面上没显示过；以后可能在游戏玩法里用到。
- **标题区右侧不放计数**：没有「可炼制 NN」，也没有「只看可制」筛选；书名区与 LV 区之后只有关闭按钮。

- **物品描边只用在深色书页上**（素材行、「用于」、底栏方槽、详情图标框）；纸卡（便签）上的物品不描边——物品自带深色轮廓，放在白纸上本来就清楚。
- 以下新增内容保留：「用于」反查、页签上的可研究小菱、「研究收录」菱形行、卡片图标背后的分类柔光、外界取得素材底部的说明句。

### 目录（`Card` / `PaperCard` / `BlankCard`，`AlchemyCatalogLayout`）

- **像素图标不随卡片旋转 / 缩放（修像素破坏）**：现状 `Card` 用 `PushFrame` 把整张卡连同图标一起旋转（±1.2～3.2°）和缩放（悬停 1.015、选中 1.045），而 `DrawPixel` 是 `PointClamp`——最近邻采样下旋转会把像素行切歪、非整数缩放会让像素一宽一窄。改法：纸面、文字、封印照旧在 `PushFrame` 里画；`BlankCard` / `PaperCard` 里的 `ItemIcon` 移到 `PopFrame` 之后，图标中心用同一个局部矩阵（绕卡片中心旋转 + 缩放）变换得到位置，再以 rotation 0、UI 缩放 1 倍绘制，并把**屏幕坐标的左上角取整**（奇数宽高的图标不要落在半像素上）。图标正立放在倾斜的纸卡上几乎察觉不到。闪光圈（`Ring`）、辉光可以继续随卡片旋转。不用线性采样替代——像素图会整体发糊。预览对应 `cardIcon` 与 `.card .ico` 的反向变换。

### 物品图标描边

- 目的：减少模组像素物品（1 贴图像素 = 1 美术像素，细节密）与原版物品（1 美术像素 = 2×2 贴图像素，颗粒粗）放在一起的突兀感。描边不改变像素密度，但给所有图标同一圈等粗的轮廓，读起来像同一批贴纸；深色底上的暗色原版物品（月光草、发光蘑菇）也更易辨认。
- **用亮边，不用暗边**：两边的美术都已自带深色轮廓，再加暗边会叠成粗黑线。
- 形状：十字形膨胀 1 个设计像素（只扩上下左右，不扩对角，跟着像素台阶走）；描边只画在图标外侧（扣掉原图 alpha），半透明的玻璃瓶身不被染色。
- 只用在深色书页（素材行、「用于」、底栏方槽、详情图标框）：薰衣草白 `rgb(236,229,247)` × .62。**纸卡上的物品不描边**（试过白边——看不出来；薰衣草边——多余，物品自带深色轮廓在白纸上已经清楚）。
- 游戏内做法建议：按（贴图, 帧）在首次绘制时用 CPU 生成描边贴图并缓存——`GetData` 取 alpha → 十字膨胀 1 texel 并扣掉原 alpha → `SetData` 成白色轮廓贴图，绘制时以对应颜色着色、垫在原图下（同样 `PointClamp`、同样取整的位置）。原版动画物品按 `Main.GetItemDrawFrame` 的帧矩形分别生成，避免相邻帧互相渗色。图标都很小，生成成本可忽略；也可以改用一个单色填充 shader，但会多一次批次切换。描边宽度按贴图像素算（1 texel），UI 缩放 1 倍时即 1 个设计像素。
