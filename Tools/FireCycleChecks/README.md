2026-11-02 实现：

- 火焰射线维持 0.7 基准 DPS，点燃容量为300点。每次付费脉冲的积累取时间保底与伤害积累的较大值：`max(攻击周期tick, 实际命中伤害 / (主体最大生命 × 0.5) × 300)`，两者不相加。默认0.3秒一次，低伤害仍约4.8秒、第17次命中点燃；高伤害累计不超过主体最大生命值50%便可点燃，蓄力时间另计。闲置清空直接复用冻结的 `ElementBuildupBuffRegistry.DefaultIdleResetTime`（900 tick，即15秒），每次新增有效积累重新计时，各玩家分别积累。短暂断攻保留进度，重复脉冲包不刷新期限。
- 燃烧持续 600 tick，射线和携火风刃的命中刷新时长。风刃、旧风刃弹幕及风球的有效命中共用传播入口；一条风刃接触燃烧目标后可以点燃后续目标。本次不改造风球自身的生成、索敌或解锁。
- 点燃积累、燃烧时长、DOT 与首次点燃奖励统一属于 `GetElementAnchorNPC` 返回的主体，与冻结使用同一套主体解析。射线命中头、身、尾都推进同一份积累；同一付费脉冲只提供一份时间保底，各体节实际结算的伤害累加后与时间保底比较，仅补足新增的差额。按弹幕标识、脉冲序号及命中体节实例去重，即使体节包跨服务器 tick 到达也不重复计算。每个主体只提供一次首次点燃奖励。已经由其他来源燃烧的目标不会因刷新再发首次奖励。NPC 实例代号随网络同步，拒绝槽位复用后的迟到命中。
- 炎爆初始及上限均为 3 层，每层基础充能 10 秒，沿用公共急速规则。手动施法沿用 50 魔力消耗，一次消耗一层；点燃赠送层数保留当前恢复进度，满层赠送则在确认时的目标脚下免费生成原有炎爆，不替换动作。炎爆本身不积累燃烧。
- 炎爆配置 `ratio: 0.3`，基础单次预算为 `3 × 基准 DPS`，不再由魔力或转换率决定。数值工具的计算、验证与编辑入口同步支持主动技能 ratio；未迁移技能继续使用原公式。单目标模拟尚不包含首次点燃的赠送层数。
- 两技能均需机械一王进度、阶段等级上限 50，并各消耗一本火焰魔法书研习。新版书使用现成六帧贴图，配方为 1 岩浆石 + 1 魔法书，在书架制作，需机械一王已击败。
- 燃烧每 30 tick 造成 `max(1, floor(角色等级 / 10))` 点固定伤害；等级取点燃或续燃者，不受装备增伤与暴击影响。KL 通过 StrikeNPC 结算并显式记录 PlayerInteraction，取代原有按目标生命百分比直接扣血。旧的通用异常扣血入口也改走 StrikeNPC。

116 项回归使用实际编译的技能、NPC 状态、技能冷却、命中请求及同步处理方法。覆盖定价、旧存档、手动成功/失败/缺魔、溢出落点/资源/动作保留、首次奖励及重复包、续燃、断续照射、风刃传播、多部位、槽位复用、序列化、客户端不重复伤害与专用服务器的远端玩家归属。闲置期限专项检查短暂断攻保留、899/900 tick 边界、临近期限时新增积累刷新计时、多次14秒间隔命中持续保留、重复包不刷新及多人独立超时。

伤害补偿检查覆盖低伤害保底、25%最大生命伤害推进半条、50%阈值、比例积累的小数保留、共享主体最大生命分母、多体节真实伤害累计、零伤害、致死回调、重复包及槽位复用。射线在 `ModifyHitNPC` 捕获命中对象和主体的实例身份，在 `OnHitNPC` 用 `damageDone` 提交；即便伤害包已使目标死亡，匹配原实例的致死命中仍可完成阈值并领取一次奖励，不复活 NPC、不向尸体添加 Buff。真实回归也检查该奖励确实经 `FireCycleSystem` 增加炎爆层数。仅击杀本身不会绕过积累阈值。
